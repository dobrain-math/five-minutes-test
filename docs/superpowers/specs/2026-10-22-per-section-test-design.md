# 유형별 24문제 · 전체 풀기 페이징 설계 (2026-10-22)

## 왜

80문제를 유형을 섞어 내던 방식을, 원장님이 «한 유형만 골라 집중해서» 또는 «전체를 유형 순서대로» 풀게 바꾸고 싶어 했다.
유형마다 10 → 24문제가 되면 1문제 = 1칸 그래프가 너무 촘촘해지므로 레이더(8각형)로 바꾼다.

## 원장님이 정한 것

- 홈: 이름 → 나이 → 권(기본연습 / 53-1권) → 유형. 유형 목록은 권을 고르면 같은 화면 아래에 펼쳐진다.
  맨 위 「전체 풀기」, 아래로 번호 붙은 유형 8개.
- 유형마다 24문제. 전체 풀기 = 유형마다 한 페이지(8페이지, 192문제), 페이지마다 시간을 잰다. 이전 유형으로 되돌아가지 않는다.
- 리포트
  - 한 유형만 풀면 그래프 칸이 아예 없다.
  - 전체 풀기면 그래프 칸 소제목이 「유형별 정답·오답」 → 「풀이 스타일 분석」. 10칸 사각형 대신 레이더 그래프, 꼭짓점에는 유형 번호.
  - 뱃지 글자 「강함·취약」 → 「강점·약점」. 기준은 24문제 중 20개↑ 강점, 7개↓ 약점(지금 비율 80%·30% 그대로).
- 짧은 링크(/r/6글자)를 받아 오는 동안 빈 화면 대신 스켈레톤.

## 내가 정한 것

- 레이더는 라이브러리 없이 SVG 로 직접(번들 유지). 데이터가 메모리에 있어 로딩 없음.
- 주소: `/test/:courseId` = 전체, `/test/:courseId/:n` = n번 유형(1부터). 리포트도 같은 모양.
- 문제 순서는 유형 안에서만 섞는다. 전체 풀기는 유형 목차 순서대로 페이지.
- 레이더 아래 목록: 번호 · 유형 이름 · 강점/약점 뱃지, 둘째 줄에 걸린 시간 + 맞힌 수 「20 / 24」.
- 한 유형 풀이 리포트는 머리 띠에 「n번 유형 · 유형 이름」 한 줄을 더 둔다. 평가문은 «모든 유형» 대신 «이 유형» 문장.
- 공유 코드 v4('4'): v3 머리(이름·나이·시간·실시일) 그대로 + 풀이 범위(0 = 전체, n = n번 유형) + 유형별 걸린 초.
  v1~v3 링크도 계속 열린다(옛 링크는 유형별 시간이 없어 목록에 시간 칸이 빠진다).
- 세션 저장 이름을 바꿔(test-session-v2) 옛 모양 세션은 버린다.
